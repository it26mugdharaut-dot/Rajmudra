RAJMUDRA DATABASE WEBSITE
=========================
1. Install XAMPP.
2. Copy this Rajmudra folder to C:\xampp\htdocs\
3. Start Apache and MySQL in XAMPP.
4. Open http://localhost/phpmyadmin
5. Import database.sql
6. Open http://localhost/Rajmudra/
Do NOT double-click index.html.
Database: rajmudra_db
Tables: products, customers, orders, order_items, reviews, enquiries
Replace 919999999999 in script.js with the intended WhatsApp number.
Copy your existing product images into the images folder.
